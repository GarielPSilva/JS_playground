JS Playground
Repositório com projetos desenvolvidos para praticar JavaScript e fortalecer meus conhecimentos em desenvolvimento web. Atualmente, reúne um contador interativo e um simulador de finanças pessoais.
Projetos
1. Contador interativo
Um contador simples criado para praticar eventos e lógica com JavaScript.

Funcionalidades
- Permite incrementar o valor do contador.
- Detecta cliques em velocidade excessiva.
- Interrompe a contagem e exibe uma mensagem de aviso quando identifica cliques rápidos demais.
Conceitos praticados
- Manipulação de eventos do usuário.
- Atualização de valores na interface.
- Condições e lógica para lidar com interações repetidas.
2. Simulador de finanças pessoais
Aplicação para acompanhar receitas e despesas, visualizar o saldo e consultar informações financeiras por meio de gráficos e filtros.

Funcionalidades implementadas
- Registro de receitas.
- Registro de despesas.
- Cálculo e apresentação do saldo.
- Visualização de informações por gráficos.
- Filtros para consultar os dados.
Armazenamento
- Utiliza localStorage para guardar dados no navegador.
Tecnologias
- HTML5
- CSS3
- JavaScript (JavaScript puro, sem framework)
Como executar
1. Clone ou baixe este repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo HTML principal de cada projeto no navegador ou utilize a extensão Live Server.
4. No contador, teste a interação com o botão e observe o comportamento quando os cliques são muito rápidos.
5. No simulador financeiro, registre receitas e despesas e explore o saldo, os gráficos e os filtros.

Sobre o repositório
Este repositório reúne projetos práticos desenvolvidos durante minha jornada de aprendizado em programação e desenvolvimento web. O objetivo é aplicar conceitos de JavaScript e aprimorar gradualmente a construção de aplicações interativas.
